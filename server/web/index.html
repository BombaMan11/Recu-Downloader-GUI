Settings

Connection

Copy both values from your browser: open the site while signed in, press F12, choose Network, select a request to the site and look under Request headers. They are saved on this computer and kept after you close the program.

Normal folders

Used by downloads without a category, and by categories that leave a folder blank. Leave a box blank to use the folder Recu.exe is in (no subfolders). To use another place, type a full path such as D:\Videos or press Browse. A video moves from the unfinished to the finished folder when it completes.

Link listener

While enabled, the program will listen for URLs copied to the clipboard from Recu.me or other Sites added to the "What Counts as a Link" box. The URLs are added into the URL box and Archived if the option is enabled.
A .txt file (also .text, .list, .lst, .md or .csv). It is created if it is not there yet, but its folder must exist. New links go above the old ones, each on a new line; the file’s other lines stay as they are. The file always gets just the plain link, even when you copy a whole entry with its times.
Every match is added. If a pattern has a group in brackets, only what the first group matches is added, otherwise the whole match. A pattern can only match within one line. Blank lines and lines starting with # are ignored; with nothing here the default is used. The default finds video links such as https://Recu.me/video/1234567/play even inside ["https://Recu.me/video/1234567/play","55:00","1:10:00"],. To add more, add a line, for example https://other\.me/v/\d+.

        

        
Only text is looked at, nothing else you copy is kept or shown, and copies marked private (private browser windows, password managers) are skipped unless you allow them above. Patterns are checked as they are saved and can’t slow the program down. The listener only ever writes to the file above.

Categories

        
Each category has its own folders for unfinished videos, finished videos and playlists. A folder left blank uses the normal folder from above. Pick a category in the box next to Add to list, or change it later by right-clicking a row.

        
Changing the category of a row that is already in the list deletes its files from the old folders and starts it again in the new ones. Removing a category here only takes it off its rows; their files stay where they are.

        

        

      


      

        
Program data folder

        

          
          

          
One folder for everything the program keeps for itself: settings.json (it holds your cookie), queue.json, Recurbate.log and the data of the program’s window (browser-data). When you save a new folder, settings, queue and log move there at once and the window’s data follows the next time Recurbate starts. A folder that already holds a settings.json or queue.json is refused so nothing gets overwritten. The choice is remembered in Recurbate.paths.json next to Recu.exe; delete that file to go back to the default, a folder called Recu-Settings next to Recu.exe.
